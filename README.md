README du projet


# Présentation du site

Ce site internet a été entièrement pensé, réalisé et conçu par mes soins.
Je n’ai reçu aucune aide extérieure pour la création de ce projet. Toutes les écritures, toutes les idées ainsi que toutes les photos présentes sur le site ont été réalisées par moi-même.


# Fonctionnement du site

Le site est construit sous la forme d’une page unique.
Cela signifie que tout le contenu est accessible en défilant de haut en bas. L’organisation suit une logique claire, pensée pour guider la lecture dans un ordre cohérent, proche d’un plan chronologique.

# En cas de problème

Avant la mise en ligne, j’ai tout vérifié afin de m’assurer que tout fonctionnait correctement.
Cependant, il se peut que de petits problèmes techniques surviennent, comme :
une interface qui ne s’affiche pas correctement,


-  un léger temps de chargement,


-  des bugs de souris ou de navigation.


Dans ce cas, il suffit généralement d’actualiser la page.
Ces problèmes viennent du fournisseur du service d’hébergement et ne dépendent pas de moi sauf erreur de ma part.
